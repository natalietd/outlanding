# Проверки в браузере: съёмка и автоматическая проверка

В этом плагине нет скриптов. Съёмка и проверка идут через браузерные инструменты Claude в сессии:
встроенный браузер, Claude in Chrome или MCP с Playwright/Puppeteer. Если браузера нет, текст
бери через web fetch, а скриншоты попроси у владельца.

Отдельная версия этого скилла с готовыми Node-скриптами для тех же двух задач лежит здесь:
https://github.com/natalietd/landing-page-builder.

## 1. Снять страницу (конкуренты, эталоны, наша страница)

Для каждой ссылки:

1. **Открой страницу в 1440×900.** Закрой баннеры cookie и промо, ничего не принимая (правила
   приватности: отказаться или закрыть). Никогда не ослабляй TLS и настройки безопасности, чтобы
   страница загрузилась.
2. **Перед прокруткой отключи плавный скролл:** выполни в странице
   `document.documentElement.style.scrollBehavior = 'auto'`. Иначе из-за `scroll-behavior: smooth`
   скриншоты ловят середину прокрутки и выходят со сдвигом.
3. **Прокрути всю страницу один раз** шагами примерно по 80% экрана, чтобы подгрузились ленивые
   картинки и блоки с появлением при скролле. Потом вернись наверх.
4. **Сними страницу по секциям:** прокрути каждую `section` (или каждый блок верхнего уровня) в
   видимую область, подожди около секунды, сделай скриншот. Если липкая шапка закрывает блок,
   сначала скрой её. Сохраняй как `research/<сайт>/sections/NN.png`, если инструмент умеет сохранять
   файлы. Иначе оставляй их в разговоре и описывай каждый в заметках.
5. **Запиши структуру:**
   - план заголовков H1–H3;
   - текст каждого CTA и куда он ведёт (`href`);
   - цены и тарифы;
   - доказательства (рейтинги, логотипы, цифры);
   - шрифты (вычисленный `font-family` у h1 и у текста), основные цвета (фон, текст, главный CTA)
     и формат медиа (экраны, видео, иллюстрации).

   Большую часть даёт дерево доступности или текст страницы.
6. **Повтори в 390×844** для мобильной версии: первый экран и всё, что ломается.

Смотри на скриншоты, а не только на текст: структура говорит о порядке, картинки — о качестве.
Некоторые сайты не открываются (таймауты, геоблокировка, сертификаты, которым браузер не
доверяет). Тогда возьми текст через web fetch или замени конкурента следующим и запиши сбой в разбор.

## 2. Автоматическая проверка нашей страницы

Делай её до любой проверки глазами. Открой нашу страницу в 1440×900, потом в 390×844. Через
браузерный инструмент (прочитать страницу, выполнить в ней короткие выражения только на чтение,
сделать скриншоты) ответь на каждую строку. **Каждый FAIL исправляется до показа владельцу.** Каждый
WARN прочитай и исправь или обоснуй.

### FAIL

| Проверка | Как проверить |
|---|---|
| **Адрес разработки или заглушка** | Ни один `href` и ни один `action` формы не содержит `localhost`, `127.0.0.1`, `0.0.0.0`, `.local`, `TODO`, `REPLACE_ME` или `example.com`. |
| **Ссылки без адреса** | Нет видимых `<a>` без `href` или с `href="#"`. |
| **Свои формы** | Нет `<form>`, кроме поля продукта, которое передаёт в `PRODUCT_URL` и помечено `data-product-input`. |
| **Ровно один H1** | `document.querySelectorAll('h1').length === 1`. |
| **Ярлыки вместо заголовков** | Нет видимых H2 из 1–2 слов («Примеры», «Шаблоны», «Тарифы»). Ярлык переносится в надзаголовок, а заголовок пишется продающий. |
| **Повторы** | Ни одна фраза из 6+ слов не встречается в 3+ видимых текстовых блоках вне FAQ. Выпиши видимый текст и найди повторы. |
| **Тёмная плита на светлой странице** | На светлой странице нет блока во всю ширину (≥90% экрана, ≥200px высотой) с почти чёрным фоном. |
| **Сильно ужатые картинки** | Нет картинок шириной ≥1000px, показанных в ≥450px при `naturalWidth / renderedWidth > 3`. |
| **Картинки, обрезанные контейнером** | Нет картинок шириной ≥120px, видимых на 5–85% внутри родителя с `overflow: hidden`, `clip`, `auto` или `scroll`. Карусели тоже. |
| **Подвал** | `<footer>` есть, и в нём юридические ссылки (конфиденциальность, условия; для платного сервиса в России ещё публичная оферта, политика обработки ПДн и реквизиты продавца). |
| **Горизонтальный скролл на телефоне** | В 390px `document.documentElement.scrollWidth <= innerWidth`. |
| **Шапка на телефоне** | В 390px шапка ≤72px по высоте и в одну строку. |
| **Ошибки в консоли** | Нет. |

### WARN

| Проверка | Как проверить |
|---|---|
| **CTA, который только скроллит к тарифам** | Кнопка про продукт («Начать», «Создать»), у которой `href` — `#pricing` или `#offer`. Подпись должна говорить, куда она ведёт, или ссылка — вести на `PRODUCT_URL`. |
| **Мелкий десктопный интерфейс** | Широкая картинка (пропорция ≥1.3) с окном приложения показана уже 700px. Открой при 100% и посмотри: если текст интерфейса меньше ~11px, обрежь до нужной панели или покажи крупнее. Галереи результатов можно исключить через `data-gallery`. |
| **Повторная картинка** | Одна и та же картинка (≥120px) стоит в двух блоках. |
| **Длинные заголовки** | H1/H2 длиннее 3 строк в 1440px (высота ÷ межстрочный интервал). |
| **Длинные надзаголовки** | Мелкие подписи капслоком длиннее ~50 символов. |
| **Наложенные картинки** | Две картинки ≥160px перекрываются на 15–95%. Для задуманной композиции это нормально, а если одна закрывает содержимое другой — это баг. |
| **Нет `alt`** | Любой `<img>` без атрибута `alt`. |
| **Стандартные маркеры FAQ** | У `<summary>` остался браузерный маркер ▶ (`display: list-item`). |
| **Запасные шрифты** | Видимый текст (включая поля и кнопки) отображается в Arial, Times или системном шрифте, хотя страница подключает веб-шрифты. Поставь `font: inherit`. |
| **Контакт в подвале** | В подвале нет почты, Telegram или телефона. |
| **Мелкие зоны нажатия** | Ссылки и кнопки ниже 36px в 390px. |
| **Пробелы в SEO** | Нет meta description, canonical или `og:image`; Tailwind Play CDN на живом адресе; адрес платформы или версии (`*.vercel.app`, `*.railway.app`, `/v3/`). См. `seo-geo.md`. |

Запиши результат в передачу: «Проверка: N FAIL (исправлены), M WARN (исправлены или обоснованы)».
